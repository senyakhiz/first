#Example 

Тестовый репозиторий для освоения github.

git clone [URL] - скачать существующий репозиторий на свой компьютер

git add . - добавить новые файлы

git commit -m "комментарий" - отправить коммит на репозиторий

git push - отправить изменения на репозиторий

git status - проверить состояние файлов
